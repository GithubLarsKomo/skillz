# performance-hotspot-analysis

Analysiert eine belastbare Performance-Baseline zusammen mit Profiling-, Query-, Trace- oder Laufzeitevidenz, lokalisiert dominierende Hotspots und klassifiziert Root Causes nach Algorithmus, unnötiger Arbeit, Datenbank, I/O, Netzwerk, Serialisierung, Cache, Parallelisierung, Runtime, Speicher, Architektur oder Build-Tooling. Verwenden vor einer Performance-Optimierung, um Mikrooptimierung nach Bauchgefühl zu vermeiden.
