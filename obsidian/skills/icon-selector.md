# icon-selector

Wählt aus einer registrierten Icon-Bibliothek das semantisch passendste vorhandene Icon und eine zulässige Farb-/Kontrastvariante anhand von Intent, Kontext, Domain, Zielmedium und Hintergrund. Verwenden intern vor dem Platzieren von Icons in Präsentationen, Dokumenten oder anderen gebrandeten Artefakten; keine Icons erfinden, umzeichnen oder regulatorische/klinische Bedeutung aus einem Symbol ableiten.
