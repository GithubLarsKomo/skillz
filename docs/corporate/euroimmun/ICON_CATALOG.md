## Selection order

1. exact **Project icon** only for that named project;
2. exact **Technique icon** when a specific assay technology is materially in scope;
3. **Portfolio & Indication icon** when the message is the corresponding clinical/portfolio field;
4. most specific **Essential icon**;
5. generic fallback only if no narrower approved icon exists.

Every selection must pass: semantic fit, claim safety, correct supplied variant, optical consistency, and textual redundancy for critical meaning.

|---|---|---|
| strategy target / Ziel | `hit the bullseye` | not analytical precision |

## Ambiguity rules

- `hit the bullseye` = target/strategy; `Precision` = analytical precision.
- `magnifying glass` = search/evidence discovery; `microscope` = experimental/laboratory science.
- `automatic lab` = concrete lab automation; Portfolio `Automation` = portfolio-level automation.
- `risk protection` = program/clinical/regulatory/commercial risk; `shield lock`/`cyber security` = access/data/cyber protection.
- `Document` = generic dossier/documentation; `Paper` = paper/publication-like artifact; `PDF` = PDF file format.
- `check mark`/`tick` = completion/approval marker; `Thumbs up` = endorsement/positive sentiment.
- `Arrow percent up/down` = explicit percentage direction; `chart increased` = general upward trend.

## Anti-patterns

Do not infer regulatory status, intended use, analytical/clinical performance, evidence maturity, or commercial certainty from an icon. Do not use Project icons generically. Do not use color/icon alone for critical status. Do not rename legacy canonical stems. Do not treat variant-like Immunoblot entries as separate technologies.
